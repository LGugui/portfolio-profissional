# app/site

Código carregado pelo `index.html`, organizado na mesma ordem visual do site.

- `00-design/`: CSS global e seções.
- `00-sistema/`: conteúdo central e utilitários.
- `01-header-nav/`: navegação fixa.
- `02-main/`: seções principais em ordem de leitura.
- `03-footer-rodape/`: rodapé.
- `04-interacoes-animacoes/`: painel de ajustes e futuras interações.
- `99-shared/`: helpers e componentes compartilhados.
- `99-assets/`: imagens e materiais visuais.
